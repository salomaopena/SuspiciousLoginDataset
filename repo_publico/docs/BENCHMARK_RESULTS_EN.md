# Benchmark Results — Reference Models

Final results, verified 2026-08-12, over the complete dataset (two
institutions, 73,528 rows), with the academic vacation period
(July-August) excluded from the train/validation/test split — see
`RISK_SCORE_METHODOLOGY_EN.md` for the full justification.

## Methodology

- **Chronological 70/15/15 split** (train/validation/test), never
  random — 48,238 / 10,337 / 10,337 rows respectively
- **Per-user cap in training**: 76 users exceeded 80 events, 5,940 rows
  removed (12.31% of training) — the most active user's training share
  dropped from 3.55% to 0.19%, validation/test untouched (see
  `docs/BACKLOG_EN.md`, and the code in `benchmark_ml.py`)
- **Decision threshold** chosen on validation (maximizing F1), never on
  the test set itself
- **`history_available`** included as a feature (confirmed genuinely
  predictive: 2.69% suspicious among users with prior history, vs 7.69%
  on their first observed event)
- Identification features (`actor_pseudo_id`) and `risk_score`/
  `risk_level` itself are **excluded** from model inputs — they are the
  comparison baseline, not an input

## Reading the results

**Random Forest has the best overall balance** (AUC-ROC=0.959,
PR-AUC=0.810), with very high precision (0.948) — few false alarms per
alert raised. The standalone Decision Tree reaches even higher
precision (0.950), at the cost of slightly lower recall.

**Every supervised model clearly outperforms `risk_score`** — the
AUC-ROC gap (0.918-0.959 vs 0.624) confirms the value of full machine
learning over a simple, few-feature score, even one that has already
been empirically validated (not the original naive formula, which
scored AUC-ROC=0.375).

**The unsupervised Isolation Forest improved substantially with
institutional diversity** — from worse-than-random performance
(AUC-ROC<0.5) on earlier, smaller, less diverse samples, to 0.766 on
this final dataset. It still falls well short of the supervised models
— expected, since it never uses the real label during training.

**`risk_score`, while systematically weaker than the full models,
still serves its purpose**: an interpretable, few-variable baseline to
measure the added value of more complex models against — exactly the
role it was assigned (see `RISK_SCORE_METHODOLOGY_EN.md`).
