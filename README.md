# SuspiciousLogin Dataset

> An anonymized dataset of successful logins, labeled as suspicious or
> not, in Google Workspace, combining two higher-education institutions.

**Status**: final dataset, version 1.0.0 (73,528 rows, two
institutions, December 2025 to August 2026).

## Limitation notice, upfront

`is_suspicious` (here, `label`) is an **operational suspicion signal**
supplied by Google Workspace, not a forensic confirmation of phishing,
credential stuffing, brute force, or actually confirmed account
compromise. This dataset describes **successful logins** — it is not a
dataset of failed attempts nor of confirmed attacks.

**Rule to always keep**: the private repository is the only source of
raw files and the restricted CSV. The public repository never receives
anything beyond `suspicious_logins_public_v1.csv` generated by
`processed.py` — not even in `.gitignore`, not even temporarily.

## How to reproduce the processing

```bash
# in the private repository, one folder under data/raw/ per institution
export HMAC_SECRET_KEY_<INSTITUTION_A>="<secret-key-a>"
export HMAC_SECRET_KEY_<INSTITUTION_B>="<secret-key-b>"
python src/processed.py
# generates suspicious_logins_public_v1.csv (copy to the public repo)
# and suspicious_logins_restricted_v1.csv (stays private only)

python src/benchmark_ml.py
# reproduces the results in docs/BENCHMARK_RESULTS_EN.md
```

`notebooks/benchmark_notebook.ipynb` reproduces the same results (tested
to match exactly) plus confusion matrices, ROC/PR/calibration curves,
feature importance, a cold-start/warm-start/mature-profile breakdown,
and a feature-group ablation study — ready to run on Kaggle against the
restricted file (kept **private** there too).

See `docs/DATA_DICTIONARY_EN.md` for what each column means,
`docs/SCHEMA_EN.md` for types and domains,
`docs/RISK_SCORE_METHODOLOGY_EN.md` for how the risk score was
calculated, and `docs/BENCHMARK_RESULTS_EN.md` for the final reference
model results.

## Institutional context

The data combines two higher-education institutions, one in Angola and
another with a strong geographic presence in Brazil. The broader
research motivation is identity security in educational SaaS/cloud
environments — **do not claim** that this dataset represents all of
Africa, all of Brazil, or higher education in general.
